# FORNO

Vedeldad napolitansk pizzeria på Södermalm. Gäster kan läsa menyn, lägga varor i korgen och betala med kort eller Swish.

Kassan är en **demo** — inga pengar dras och inget kort sparas.

## Funktioner

- Meny med klassiker, specialare, vegetariskt, tillbehör och dryck
- Storlek 30 eller 40 cm på pizzorna
- Avhämtning på Åsögatan 48 eller hemleverans (gratis över 300 kr)
- Demobetalning: kort (t.ex. `4242 4242 4242 4242`) eller Swish
- Live orderstatus i webbläsaren
